# Geoteknik Rapor — deneme sürümü

EK-12 "Parsel Bazında Zemin ve Temel Etüdü Geoteknik Raporu" taslak aracının denetim için yayınlanmış derlenmiş hali.

Açmak için: https://alperenbayramm.github.io/geodemo-demo/

- Başlangıç ekranında **Örnek raporu incele** dolu, sentetik bir raporu açar.
- Mavi değerlere tıklayınca hesabın adımları sağ panelde görünür.
- **Raporu gör** basılacak hali, **Word indir** Word çıktısını verir.
- Girilen veriler yalnız tarayıcınızda saklanır; hiçbir sunucuya gönderilmez.
